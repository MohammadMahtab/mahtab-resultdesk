## Features

|                        |                                                  |
| ---------------------- | ------------------------------------------------ |
| **School and College** | Percentage, grade and division, or SGPA and CGPA |
| **Exact results**      | Integer maths, so no rounding surprises          |
| **Target planner**     | Shows the marks you still need to reach a target |
| **Custom rules**       | Set your own passing marks and grade scale       |
| **Print**              | A4 result summary                                |
| **Private**            | Runs in your browser and nothing is uploaded     |

## Usage

- **School:** enter the marks and maximum marks for each subject. Use `AB` for absent and `NA` for a subject not taken.
- **College:** choose **Marks** to get your SGPA (add the credits), or **CGPA** to convert it to a percentage.
- **Settings:** change the passing marks and the grade scale.

### CGPA to percentage

| Formula            | Used by                          |
| ------------------ | -------------------------------- |
| CGPA × 10          | DU (UGCF / NEP), Anna University |
| CGPA × 9.5         | DU (CBCS), CBSE                  |
| (CGPA − 0.75) × 10 | VTU, AKTU                        |

Rules differ between universities, so use the one yours follows.
